# Telemetry

Система сбора телеметрии с 4 источников. Валидация значений, запись в SQLite через самописный WAL, 20 трендов, окно видимости на 3600 значений.

## Запуск

```
pip install -r requirements.txt
python demo.py
pytest tests/ -v
```

## Что делает система

1. Раз в секунду собирает данные с 4 источников. Каждый источник отдаёт от 100 до 600 объектов со скалярным значением (число или bool).
2. Валидирует: значение валидно, если это число или bool. Строки, `None`, списки — невалидны.
3. Валидные значения → таблица `raw_values`.
4. Невалидные → таблица `invalid_values` (с причиной брака).
5. Считает 20 трендов из собранного батча.
6. Тренды пишет в SQLite **через самописный WAL** (`wal.log`).
7. Хранит последние 3600 значений каждого тренда в памяти (ring buffer).
